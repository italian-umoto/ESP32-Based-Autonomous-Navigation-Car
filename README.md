## How It Works
WebSocket commands:

```text
MAGICSMOKE67 set: STATE=7,1  (start/restart solo bot #1)
MAGICSMOKE67 set: STATE=7,2  (start/restart solo bot #2)
MAGICSMOKE67 set: STATE=0,0  (stop and return to manual mode)
```
